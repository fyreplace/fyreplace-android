# AGENTS.md — fyreplace-android

Android client app for [Fyreplace](https://fyreplace.net) — Kotlin, Jetpack Compose, Hilt,
Gradle (Kotlin DSL), Java 25 toolchain, `compileSdk` 37 / `minSdk` 24.

- gRPC stubs are generated by the **Wire** plugin from the `protos` submodule
  (`app/src/legacy/proto/protos`, github.com/fyreplace/fyreplace-protos). The OpenAPI kotlin
  client is generated from `app/src/main/assets/openapi.yaml` into `build/openapi`. **Never edit
  generated code**: change the `.proto`/spec sources (in the submodule for protos), commit there,
  then bump the pointer here.

## Fyreplace-wide rules

- **Minimal comments** — write self-explanatory code with precise naming. Add a comment only for a non-obvious constraint or an intentional deviation; never narrate what the code already says.
- **Conventional commits** — commit messages follow the [Conventional Commits](https://www.conventionalcommits.org) format: `type(scope): subject` (e.g. `feat(ui): add dark mode`). Keep them short: a concise subject line (≤ 72 characters) and, when needed, a brief body.

## Commands

| Task | Command |
|---|---|
| Build | `./gradlew build` |
| Run unit tests | `./gradlew test` (`app/src/test`) |
| Run instrumented tests | `./gradlew connectedAndroidTest` (`app/src/androidTest`, custom `TestRunner`) |

## Build variants and config

- Flavor dimensions: `version` (`next` / `legacy`) × `ecosystem` (`libre` / `google`) — e.g.
  `./gradlew assembleNextGoogleRelease`.
- Versions are derived from git at build time (latest tag + commit count, with a suffix from the
  branch: dev/release/hotfix/main) — never bump versions by hand.
- Release signing credentials and the Sentry DSN come from env vars or `local.properties`
  (keystore.path/password, key.alias/password, sentry.dsn) — `local.properties` must never be
  committed.
- The default backend environment is a generated proto `Environment`: `LOCAL` in debug,
  `DEV`/`MAIN` in release.
